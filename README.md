# Instarchive — Іван Франко

Авторська навчальна односторінкова вебсторінка про Івана Яковича Франка (1856–1916), створена у форматі уявного Instagram-профілю.

## Швидкий запуск

Відкрийте `index.html` у браузері. Ніяких збірок, встановлень пакетів, серверів чи API-ключів не потрібно.

Або локальний сервер:

```bash
python -m http.server 8000
```

Потім відкрийте `http://localhost:8000`.

## Що працює

- Адаптивна верстка: десктоп, планшет, телефон.
- 12 тематичних постів про життя і творчість Франка.
- Перегляд дописів у модальному вікні, переходи між дописами стрілками.
- Шість «історій» з автоматичним перегортанням.
- Пошук за назвою, роком, містом та текстом поста.
- Вподобання, збережені дописи, підписка та локальні коментарі.
- Світла й темна теми, збереження стану в localStorage.
- Клавіатурна навігація: Escape, стрілки вліво/вправо.
- Розділ біографії з історичною хронологією.

Всі взаємодії демонстраційні: сервер, реєстрація і фактична соціальна мережа відсутні.
